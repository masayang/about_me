# Images and Media / 画像とメディア

This directory is for storing images, screenshots, and other media files used in the resume and portfolio.

このディレクトリは、レジメやポートフォリオで使用する画像、スクリーンショット、その他のメディアファイルを保存する場所です。

## Organization / 整理方法

```
docs/
├── images/
│   ├── profile/          # Profile pictures / プロフィール写真
│   ├── portfolio/        # Portfolio project screenshots / ポートフォリオのスクリーンショット
│   └── certifications/   # Certification images / 資格証明書の画像
└── README.md
```

## Usage / 使い方

Place your images in the appropriate subdirectories and reference them in your resume or portfolio using relative paths.

適切なサブディレクトリに画像を配置し、相対パスを使用してレジメやポートフォリオから参照してください。

Example / 例:
```markdown
![Project Screenshot](../docs/images/portfolio/project-name.png)
```
